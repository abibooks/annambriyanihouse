ANNAM BIRYANI HOUSE — BOOTSTRAP SCROLL-REVEAL RESTAURANT WEBSITE
=================================================================

Pages:
- index.html   Home / featured biryani / drinks / CTA
- menu.html    Biryani, starters, vegetarian options, drinks
- story.html   Restaurant story and values
- contact.html Table booking enquiry form, contact details and Google Map

Assets:
- assets/css/style.css  Custom responsive premium theme
- assets/js/main.js     AOS scroll-reveal setup, year and minimum booking date

DESIGN
- Bootstrap 5.3.3
- AOS 2.3.4 scroll-triggered reveal animation
- Dark roast / warm cream / saffron-gold palette
- DM Sans + Playfair Display
- Responsive menu cards, image reveals, floating WhatsApp button
- Google Map set to Anna Nagar, Chennai as a demo location

FORM SUBMISSION (NO CUSTOM BACKEND)
- The contact/booking form action is already configured to:
  https://formsubmit.co/abi.books0@gmail.com

- Test the form after uploading the website and check inbox/spam.

BEFORE PUBLISHING
1. Replace the demo WhatsApp number 919876543210 throughout the HTML files with your real number (country code, digits only).
2. Replace +91 98765 43210 and the Anna Nagar demo address with actual restaurant details.
3. Update the Google Maps iframe URL in contact.html to your exact location.
4. Check every menu item, photo, price and dietary description. The current content and prices are placeholders.
5. Update the opening hours and social profile links.
6. Add a privacy policy if collecting customer information.
7. Make sure your restaurant's name and logo are authorized for use.

PREVIEW
Extract the ZIP and open index.html in a browser. Internet access is required for Bootstrap, Google Fonts, Bootstrap Icons, AOS, remote photos and the Google Maps embed.

SCROLL REVEAL
The website uses AOS data attributes such as data-aos="fade-up", "fade-right" and "zoom-in".
Official project documentation: https://github.com/michalsnik/aos
